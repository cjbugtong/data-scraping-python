# Data Scraping Python

Python web scraping project that extracts data on top companies in the Philippines from Wikipedia using BeautifulSoup, Requests, and Pandas.

The project collects, cleans, organizes, and exports structured company data into CSV format for analysis and reporting.

---

## Features

- Scrapes company data directly from Wikipedia
- Extracts table headers and company records
- Cleans and formats scraped data
- Stores data in a Pandas DataFrame
- Exports results into a CSV file
- Runs inside Jupyter Notebook

---

## Technologies Used

- Python
- BeautifulSoup4
- Requests
- Pandas
- Jupyter Notebook

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/cjbugtong/data-scraping-python.git
```

### 2. Open the project folder

```bash
cd data-scraping-python
```

### 3. Start Jupyter Notebook

```bash
jupyter notebook
```

### 4. Open the notebook file

```bash
TopCompaniesInPH_WebScraping.ipynb
```

### 5. Run the notebook cells step by step
